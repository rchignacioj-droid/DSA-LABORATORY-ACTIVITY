Stack Delimiter Checker

Description
This project is a Java program that uses a Stack to check if delimiters are properly matched.

Delimiter Pairs
- Parentheses: `()`
- Brackets: `[]`
- Braces: `{}`

 Features
- Uses Stack data structure.
- Performs PUSH, PEEK, and POP operations.
- Checks properly matched delimiters.
- Displays stack execution trace.
- Identifies valid and invalid sequences.
Sample Input

Valid Input:
`{[()]}`

Invalid Input:
`{[(])}`
